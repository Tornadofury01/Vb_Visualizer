# Developer guide

Docs for people building VB Visualizer. Start with **Getting started** to run it,
then read the **Visualizer** section to understand how the app is put together.

| Page | Read it when you want to… |
| --- | --- |
| [Getting started](./getting-started.md) | Clone, install, and run the app locally |
| [Visualizer › Architecture](./visualizer/architecture.md) | Understand the 3D scene and its component boundaries |
| [Visualizer › File reference](./visualizer/file-reference.md) | Look up what a specific file does |
| [Visualizer › Decisions](./visualizer/decisions.md) | Know why a stack or design choice was made |

The docs follow [The Good Docs Project](https://www.thegooddocsproject.dev/template)
templates (Quickstart, Concept, Reference).

**Keep docs next to code.** If a change alters how the app runs or how the scene
is structured, update the matching page in the same pull request.
